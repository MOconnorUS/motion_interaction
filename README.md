# Welcome to J.A.R.V.I.S
## Join | Automatic | Remote | Virtual | Interaction | System

# About
J.A.R.V.I.S is a unique tool developed for the Hack OH/IO 2025 Hackathon by team 85 Jamm. J.A.R.V.I.S allows its user to interact with their personalized computer via their camera. 

With J.A.R.V.I.S, you can control your computer hands-free using gestures to:
- Move the cursor
- Perform left-click actions
- Switch between applications (Alt + Tab)
- Switch between browser tabs (Ctrl + Tab)
- Scroll up and down
 

# Technology Used
J.A.R.V.I.S leverages Python to install all necessary tools as well as being the foundational language for the project. Through Python libraries such as OpenCV, Metapipe, and ctypes are utilized to accomplish the various functionalities needed. OpenCV allows for the camera capture and control. Metapipe enables the capturing of hand landmarks which further allows for gesture capture. Finally ctypes performs all peripheral interactions (mouse & keyboard) with the computer.

# How to Use
1. Clone the repository
2. Create a Python virtual environment
3. Activate your virtual environment and run setup.bat
4. Run the camera python file: ```python camera.py```
